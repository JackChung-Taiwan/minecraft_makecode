遊樂園設施（完整匯入）

一次匯入完整遊樂園設施程式。

https://makecode.com/_3bAMha6PJH1D
1開啟 MakeCode 並匯入程式
  1. 開啟 Minecraft 教育版，進入 MakeCode 編輯器。
  2. 點選頁面右上角的「匯入」按鈕。
  3. 在匯入視窗中，點選「匯入 URL…」。
2貼上專案 URL 並確認匯入
  1. 將本頁提供的 MakeCode 專案網址貼入輸入框。
  2. 按下「繼續！」，等待專案載入。
  3. 匯入完成後，程式積木會顯示在 MakeCode 編輯器中，即可調整參數並執行。
